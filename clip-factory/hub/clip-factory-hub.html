Run it

In the clip-factory folder: right-click empty space → Open in Terminal, then paste one command.

Start Clip Factory
docker compose up
Leave the window open. Ctrl + C stops it.
Check everything
docker compose run --rm worker npm run doctor
Prints ✅ / ⚠️ / ❌ with a fix for each line. Run it after changing keys.
Update (newest yt-dlp + Claude's changes)
docker compose build --pull
Do this on launch morning, and after downloading a new version of the code.
Edit your keys
notepad .env
Each key right after its = sign. Never screenshot or share this file.

Getting to launch

Tick things off as you go. Saved in this browser.

Open it like an app in Chrome

  1. Open localhost:3000 in Chrome.
  2. Menu ⋮ → Cast, save and share → Install page as app… (older Chrome: More tools → Create shortcut, tick "Open as window").
  3. Clip Factory gets its own window and a desktop icon.

What's new Building now

  • Any game. Approved streamers get clipped whatever they're playing, not just GTA 6.
  • YouTube scanner. Approve a channel by @handle; it cuts the most-replayed moments of their newest videos.
Only approved creators get clipped. Big creators often run paid clipping campaigns (pay per 1,000 views). That's the money route, and it keeps your accounts safe from copyright strikes.
